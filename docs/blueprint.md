# **App Name**: జ్ఞాన బోధ

## Core Features:

- Lord's Day List View: A web page displaying an easily navigable list of all 52 'Lord's Days' (ప్రభువు దినములు), allowing users to select and view specific sections.
- Catechism Detail View: Dedicated web pages for each 'Lord's Day', clearly presenting the Question (ప్రశ్న) and Answer (జవాబు) in Telugu for focused study.
- Firestore Data Integration: Securely retrieve and render all catechism content, including 'Lord's Day' titles, questions, and answers, from a Firebase Firestore database.
- Telugu Content Search Tool: An AI tool allowing users to search the Catechism text in Telugu using keywords, phrases, or thematic queries, and retrieve relevant passages efficiently.
- Distraction-Free Reading Mode: A UI feature to enhance readability by providing a clean, minimalistic view for catechism answers, removing non-essential elements.

## Style Guidelines:

- Primary color: A calm, soft blue (#5E89BB), representing wisdom and contemplation, offering a stable visual foundation for text.
- Background color: A very light, almost white, desaturated blue (#EEF1F6) to provide a spacious and eye-friendly canvas for reading extensive content.
- Accent color: A brighter, lighter blue-cyan (#99D9E6), used subtly for interactive elements and highlights, ensuring clarity without distracting.
- Headline and body text font: 'Gidugu' or 'Nirmala UI' for high-quality Telugu Unicode display, ensuring excellent readability. A line height of at least 1.5 should be applied to all body text. Note: currently only Google Fonts are supported.
- Use minimalist, clear, and context-appropriate icons for navigation and core actions, aligning with the app's clean and distraction-free design ethos.
- A responsive two-panel layout, seamlessly adapting from a single-column display on mobile to a side-by-side list and detail view on larger screens, with ample whitespace for clarity.
- Incorporate subtle and elegant transition animations between pages and views to provide a smooth, unobtrusive user experience.
